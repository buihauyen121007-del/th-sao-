✦ Lưu đồ Quy trình Đầy đủ: Lark Base → AI Agent Đại Thành → Xuất HTML (BC & Dashboard)

Chuyển thể từ bản nháp bảng trắng kèm đầy đủ quy tắc (rules_config.json), ánh xạ schema, 3 kỹ năng, 7 công cụ và cổng kiểm soát con người (HITL 1–3).

Bảng tham số & đối chiếu từng bước trên Lưu đồ

Khối quy trình Dữ liệu / Công cụ / Quy tắc áp dụng Nhánh OK Nhánh KO & Vòng lặp
1. Lark Base 5 nguồn (~30 HS/tháng, 3 khu vực): applicants + dossiers/*.txt, existing_partners, existing_pos, verification_results, rules_config.json & schema_mapping.json. Ghi SHA-256. OK → Cleaning KO → Lỗi → Lark Base
2. Cleaning tool_load_and_extract_dossier: ánh xạ bí danh Anh/Việt, trích văn bản kèm evidence_quotes, chuẩn hóa không dấu/đơn vị, tách missing_fields. OK → Process KO → Lỗi → Lark Base
3. Process Skill 1–3 & 7 Tools (LLM / Local): đối chiếu MST, tên ≥82%, GPS ≤5.0 km, cổng ≥40m2 / ≥1 KTV / ≥150tr, công nợ ≤30 ngày / ≤500tr / ≤5%, chấm 4 tiêu chí (25-30-20-25) có trần thực chứng, cảnh báo cam kết ≥400tr, audit .jsonl. → Verify Nhận vòng lặp từ Feedback
4. Verify Kiểm tra bất biến cấm Tiếp tục khi còn IDENTITY_DUPLICATE, TERRITORY_CONFLICT, POLICY_EXCEEDED, MISSING_EVIDENCE + kiểm soát HITL-1/2/3 (KD – VH – TC – Trưởng phòng PTKD). OK → Xuất (html) KO → Feedback → Process
5. Xuất (html) → BC & Dashboard Phát hành qua Web Server (http://localhost:8055/): báo cáo bang_de_xuat_khu_vuc.csv, bao_cao_tong_hop.md, bản nháp Email (BC) & Web App Melody Hồng (Dashboard) + kiểm thử 10/10 PASS. Bàn giao PTKD —
